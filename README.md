# e-plantShopping

## Project Overview

**e-plantShopping** is an online plant shopping application that allows users to explore and purchase a variety of plants conveniently. The application aims to provide a user-friendly shopping experience for plant lovers, making it easy to browse plants and discover options for home gardening.

## Features

- Browse a variety of plants.
- Explore plant details and available products.
- Enjoy a convenient online shopping experience.
- Discover plants suitable for home and garden decoration.

## Purpose

The purpose of this project is to develop an e-commerce application focused on plant shopping while gaining practical experience in web application development.
